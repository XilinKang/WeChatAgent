# 设置同步与微信重新连接

## 保存与刷新

页面保存设置时会核对当前版本，防止一个窗口覆盖另一个窗口的新设置。

- 点击刷新会读取最新设置，并保留本页未保存的改动。
- 保存时发现其他窗口已修改配置，会自动合并不同设置项的改动，然后重试保存。
- 同一设置被两边修改时，会显示选择窗口；逐项选择保留本页内容或使用已保存值。取消后保留草稿，不覆盖后台。
- 允许好友和群聊名单作为完整设置项核对，不自动混合两边的授权增删。
- 刷新期间新输入的内容仍会保留。保存期间继续输入的内容也会保留为下一次草稿。
- 微信账号切换后，不会把旧账号页面的未保存聊天设置自动应用到新账号。

已保存的聊天设置与微信连接验证分别显示结果。即使连接验证失败，已经保存的好友名单不会被误报为未保存。页面中与后台相同的旧连接表单会自动同步，不再重复提交过期的连接版本。

## 自动连接的登录顺序

已有读取凭据时，程序优先验证并复用，不要求重新登录。

首次连接若微信已经登录，而且没有可复用的有效凭据，会立即提示使用“重开微信并连接”，不再只等待获取超时。

1. 点击“重开微信并连接”。
2. 核对列出的匹配微信程序，确认停止。程序只操作核验过的本项目匹配微信，不停止其他微信或 DSH。
3. 程序重新打开匹配微信，自动开始连接检查。
4. 等待“读取组件已准备好”后，在微信中完成登录。程序随后核对实时账号、验证数据库并保存凭据。

退出账号再登录可能不会重新初始化数据库，因此恢复流程使用完整退出微信进程再打开。程序不能代替用户完成微信登录；登录过早或等待超时仍可从同一入口重试。任何验证失败都保留原连接配置与聊天历史。

发送组件的版本要求保持为 Windows x64 微信 4.1.10.27。这项流程修复不提供对其他微信版本的适配。
